## 从一个具体问题开始

我想借助 AI Agent 理解并二次开发现有项目，同时把学习路线和成果整理成一个可以长期更新的个人空间。

## 已经完成的步骤

- 准备 Node.js 开发环境。
- 安装 OpenCode，并验证它可以运行。
- 选择 Tailwind Next.js Starter Blog 作为个人网站的基础。
- 在 Windows 上安装项目依赖，启动本地服务，验证主要页面可以访问。

## 正在探索

DeepSeek API 可以为编程 Agent 提供模型能力，OpenCode 则组织读文件、修改代码和运行命令等工具。下一步需要完成实际连接，并用一个小任务检验完整流程。

这个网站正在从默认博客改造成学习与作品空间。当前页面展示的是进行中的实践，不是已经完成的能力清单。

## 下一步

1. 补充真实的个人资料和联系方式。
2. 完成一次范围明确的项目二开，记录需求、方案和验证结果。
3. 添加截图与复盘，再考虑公开部署。

比起一次搭出所有功能，我更希望每次学习都能留下一个可以验证的小成果。
